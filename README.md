# 宗诗童 · 视觉设计作品集

蓝天白云风格的个人作品集网站，包含个人介绍、三个可拖拽能力贴纸，以及按类别集中展示的作品。

## 在线访问

[打开已发布的作品集](https://visual-playground-studio-0911.banatinzone.chatgpt.site/)

## 内容

- 个人设计：品牌、包装、海报、书籍、字体、纹样、IP 与交互设计。
- 运营能力：账号运营与视频剪辑。
- 其他能力：摄影、绘画与线上线下物料制作。
- 共 103 件素材，支持图片放大、同类切换、PDF 页面预览与视频播放。

## 本地预览

这是纯静态网站，无需安装前端依赖。下载仓库后，在项目目录运行：

```sh
python -m http.server 8080
```

然后打开 http://localhost:8080 。也可以直接打开 index.html 查看页面。

## 文件说明

- `index.html`：个人介绍与页面结构。
- `style.css`：蓝天主题、贴纸与响应式排版。
- `app.js`：拖拽、分类切换与作品预览。
- `data.js`：作品目录与素材路径。
- `assets/`：网站使用的图片、缩略图与视频。

修改个人资料可编辑 index.html；新增作品时将素材放入 assets/ 并更新 data.js。
